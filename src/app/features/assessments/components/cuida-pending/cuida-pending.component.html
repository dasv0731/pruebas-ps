CUIDA — Corrección externa (TEACorrige)

¿Cómo funciona la corrección del CUIDA?

  1. El evaluado ya ha completado el cuestionario en la aplicación.
  2. Descargue el archivo XML y súbalo a TEACorrige para obtener los resultados.
  3. Una vez TEACorrige le devuelva los valores, transcríbalos aquí.
  4. La aplicación generará la visualización del informe.
