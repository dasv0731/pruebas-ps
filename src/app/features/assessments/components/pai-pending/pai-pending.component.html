PAI — Corrección externa (TEACorrige)

¿Cómo funciona la corrección del PAI?

  1. El evaluado ya ha completado el cuestionario en la aplicación.
  2. Descargue el archivo XML y súbalo a TEACorrige para obtener los resultados.
  3. Cuando TEACorrige le devuelva las puntuaciones T de cada escala, transcríbalas aquí.
  4. La aplicación generará el perfil clínico con la interpretación.

Paso 1: Exportar para TEACorrige

Descargue el archivo XML con las respuestas del evaluado (344 ítems, formato F/LV/BV/CV).

Paso 2: Transcribir puntuaciones T

Cuando TEACorrige le devuelva las puntuaciones T de todas las escalas y subescalas, ingréselas manualmente.

Nombre del sujeto en el XML

Nombre sugerido basado en las iniciales y la edad. Puede editarlo si TEACorrige requiere otro formato.
